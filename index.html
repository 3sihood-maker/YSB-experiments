Experiments
Adding another? Drop the HTML file into this folder and add one line to the EXPERIMENTS list at the bottom of this page — the number in the heading counts the list, so it looks after itself. For the thumbnail, save a 480×300 JPEG into thumbs/ named after the page (the-floor.html → thumbs/the-floor.jpg). Miss it out and the card shows a plain label instead. The kind on each entry is what By type groups on, so spell it the same as the others to join a group — or spell it differently and it starts its own, slotting in where the * sits in TYPE_ORDER.
